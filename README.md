# Blinkit Quick Order System

A beginner-friendly Python project that simulates ordering groceries on a quick-commerce app like Blinkit.

## Real-life problem
Customers need a fast way to pick groceries, apply coupons, see the final bill (with delivery charges), and get a delivery estimate. This project models that flow in the terminal.

## Features
- Browse a product catalog
- Add multiple items with quantities to a cart
- Apply coupons (BLINK10 = 10% off, FIRST50 = Rs 50 off)
- Free delivery above Rs 199, otherwise Rs 25 fee
- Bill with subtotal, discount, delivery and total
- Random delivery estimate (8 to 15 minutes)
- Orders saved to orders.json and viewable later

## How to run
1. Install Python 3.8 or newer
2. Run: python main.py
